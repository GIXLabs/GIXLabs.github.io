# Bambu Lab X1 Carbon

The Bambu Lab X1 Carbon is a fast, enclosed 3D printer available in the Labs. It is well-suited for prints that benefit from higher speeds, an enclosed build chamber, or materials beyond standard PLA.

For step-by-step instructions on how to set up a print and use the printer, see the how-to guide:
